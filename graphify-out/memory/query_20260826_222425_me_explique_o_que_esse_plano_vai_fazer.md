# Q: me explique o que esse plano vai fazer

## Answer

Expanded from original query via vocab: [affiliate, capture, extension, publication, product, tenant, auth, link, token, schema, supabase, vitrine]. O plano transforma o BizuMiner de uma vitrine da casa alimentada por sweep em um gerenciador multi-afiliado com captura humana. Primeiro contém o acesso automatizado ao Mercado Livre; depois cria identidade/configuração por afiliado, isolamento por tenant e publicações com slugs próprios; então substitui a tag global por link resolvido no servidor. A extensão é pareada por dispositivo, injeta botões no catálogo, envia somente o card explicitamente clicado para a API, usa requestId para idempotência e mantém apenas uma outbox temporária. Gestão, revogação, testes A/B e validação ponta a ponta fecham o rollout.
