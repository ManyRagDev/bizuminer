## Contrato interno

Pool real único por processo e string de destino, estável em globalThis durante recargas Next. Máximo3, prepare:false, idle_timeout5s, connect_timeout10s e max_lifetime60s, application_name bizuminer-web. Não guardar tenant/ator no pool. String de conexão nunca é logada. Não alterar SSL fora do comportamento existente.

Cada db() cria handle lógico próprio. end() é idempotente e encerra apenas esse handle, nunca mata transação/consulta de outro; chamadas futuras pelo handle fechado falham. begin captura contexto daquele handle e autoriza dentro da tx, preservando assinaturas/options e erros/rollback. Não mutar begin no objeto compartilhado. Tags, unsafe e helpers do Postgres.js continuam compatíveis. Fábricas de teste injetadas em DAL não são alteradas. Reutilizar conexões físicas em vez de fechá-las a cada finally é a mudança interna intencional; idle_timeout libera sockets ociosos. Falha/rollback/cancelamento deve devolver capacidade do driver. Limite é por processo, não promete teto global entre réplicas/CLIs independentes.
