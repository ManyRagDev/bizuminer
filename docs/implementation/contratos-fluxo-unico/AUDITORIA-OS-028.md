# AUDITORIA-OS-028 — entrega técnica e segurança

**Veredicto: NAO_CONFORME.** Modo `entrega`, 19/10/2026. Critérios congelados: [OS-028](OS-028.md), AC-028.1–AC-028.5; relato do executor: [RESULTADO-OS-028](RESULTADO-OS-028.md). Versão auditada: `main` `43700c59f4e24f68f3a2e32c20ee5147fa4816cd` mais working tree local extenso, ainda não commitado (inclusive os documentos desta pasta, não rastreados). Os SHA-256 de OS, resultado, `comparison-evidence.ts`, `editorial-selection.ts`, `editorial-selection-db.ts` e `curation-db.ts` foram iguais no início e no fim da revisão; não foi observada edição simultânea desses caminhos. O cenário feliz da fixture passa, mas as fronteiras adversariais de procedência, retenção e alegação pública falham. **Não homologar a OS-028 nem integrar alegações comparativas públicas antes do fechamento dos achados obrigatórios.** Não foi observado vazamento de dados entre tenants; a falha de segurança editorial é publicar afirmação cuja base deixou de ser válida.

## Verificações independentes e limites

- `node --import tsx comparison-flow.test.ts` em `tools/editorial-tests`: **5 cenários passaram** em PGlite. `npm test --prefix tools/editorial-tests`: **29 cenários passaram**; esse comando não inclui `comparison-flow.test.ts`.
- Testes focados de `product-family`, `comparison-evidence`, `editorial-selection`, `editorial-groups`, `curation-snapshot` e `ai-curation`: **passaram**. Chamadas diretas às funções públicas reproduziram BUG-017/018/019/020/022/023. O ensaio PGlite adicional reproduziu BUG-021, com saída `before [main_a]`, `after_price_change [main_a]`, `after_alt_rejected [main_a]`.
- `npm run typecheck --prefix packages/persistence`, `npm run typecheck --prefix packages/web` e `npm run build --prefix packages/web`: **código 0**. Não demonstram os aceites comportamentais.
- `npm test --prefix packages/persistence`: **8 arquivos passaram, 1 falhou**; `ml-manual-only-entrypoints.test.ts` falhou por `spawnSync ... EPERM` no sandbox. `npm test --prefix packages/web`: **70 arquivos passaram, 2 falharam**; `qr-service.test.mjs` falhou ao consultar interfaces de rede (`uv_interface_addresses`), e `capture-process.test.mjs` falhou ao esperar saída de subprocesso neste ambiente. São falhas fora do delta funcional da OS-028, registradas como **limitação de diagnóstico ambiental**, sem novo BUG desta ordem. O relato do executor de suítes verdes em outro ambiente não foi reproduzido integralmente aqui.
- A fixture de AC-028.1 simula recaptura por SQL direto, não pela função de ingestão; a unicidade real de recaptura permanece **não verificada nesta auditoria**. Nenhum teste remoto, navegação autenticada, chamada paga, deploy ou migration foi executado.

**Fechamento:** nova execução do mesmo AC e do respectivo contraexemplo para cada BUG na mesma versão corrigida, seguida da fixture `comparison-flow`, testes focados e bateria geral em ambiente que permita os três testes hoje limitados. Não reabrir aceites por preferência arquitetural; qualquer caminho protegido necessário exige revisão explícita da OS.
